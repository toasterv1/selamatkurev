🛡️ SelamatKu

Aplikasi pendeteksi bencana berbasis lokasi yang membantu Anda:

  • Deteksi gempa terkini dari BMKG (data real-time)
  • Zona risiko tsunami berdasarkan kedalaman & magnitudo
  • Jalur evakuasi optimal menggunakan OSRM routing engine
  • Tempat berlindung terdekat dari OpenStreetMap (Overpass API)
  • Mode offline — data terakhir tetap tersedia tanpa internet
  • Notifikasi gempa — peringatan langsung saat gempa besar
  • Family sharing — bagikan posisi ke keluarga via SMS/WA
  • Riwayat & favorit — simpan tempat aman dan lacak evakuasi

⚠️ Disclaimer

Aplikasi ini bersifat informasional. Selalu ikuti instruksi resmi BPBD dan otoritas setempat. Data mungkin tidak selalu akurat atau up-to-date.

Tips Kesiapsiagaan

  1. Simpan nomor darurat: 112 (nasional), BPBD kota
  2. Tentukan titik kumpul keluarga sebelum bencana terjadi
  3. Siapkan tas siaga: air, makanan, obat, dokumen penting
  4. Kenali jalur evakuasi di lingkungan Anda
  5. Jauhi pantai jika ada peringatan tsunami

📱 Install Aplikasi

Untuk pengalaman terbaik, install sebagai aplikasi:

  • Android/Chrome: Menu ⋮ → "Install app" / "Tambahkan ke layar utama"
  • iOS/Safari: Tombol Share → "Tambahkan ke Layar Beranda"
